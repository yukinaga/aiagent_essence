# AIエージェントの本質 ―AIに仕事を「任せる」とはどういうことか?仕組みと任せ方を原理から理解する―
Udemyコース『AIエージェントの本質 ―AIに仕事を「任せる」とはどういうことか?仕組みと任せ方を原理から理解する―』の講義メモです。  
  
質問に答えるだけだったAIが、いま、自分で調べ、判断し、実行する「動くAI」へと変わりつつあります。期待も不安も広がっていますが、その両方に共通しているのは、「AIに任せると実際に何が起きるのか」が見えていないことです。  
  
この講座は、AIエージェントの使い方講座ではありません。エージェントとは何でできていて、どう動き、なぜ失敗し、どう任せればよいのか。その原理を、コードも数式も専門用語も使わずに、根本から理解する講座です。
